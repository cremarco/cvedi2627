Come consultare la raccolta
I percorsi del catalogo e dell’indice sono relativi a materiali/approfondimenti/; le cartelle degli anni hanno formato AAAA-AAAA. I nomi originali e i collegamenti alle fonti restano nei campi fonti del catalogo.
indice.txt elenca i file e i riferimenti alle fonti. catalogo.json contiene tutti i nomi originali, i link alle copie e le impronte SHA-256. Gli originali su Drive, Gmail ed e-learning restano nelle loro posizioni.

Il controllo del 5 ottobre 2026 conferma tutti gli 89 percorsi del catalogo: 88 file hanno dimensione e SHA-256 corrispondenti; per il file gestito da Git LFS, OID SHA-256 e dimensione corrispondono al puntatore locale. Nessun file candidato pertinente rimasto da scaricare. Esclusi documenti amministrativi, rapporti di valutazione, tesi, progetti ed esercizi di altri corsi. La ricerca non può attestare l’esistenza di file eliminati o non accessibili agli account collegati.

Git LFS
Il PDF indicato con git_lfs: true nel catalogo è archiviato con Git LFS. Un checkout che mostra un piccolo file di testo con le righe version, oid e size contiene il puntatore, non il PDF. Con Git LFS installato, eseguire dalla radice del repository:

git lfs pull

Il download deve corrispondere allo SHA-256 e alla dimensione in byte registrati nel catalogo. La regola per il percorso corrente è in .gitattributes.
